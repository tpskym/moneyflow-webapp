# M-Flow

Мобильное PWA-приложение для личного учета доходов и расходов. Работает локально в браузере, умеет сохранять данные в Google Drive, выдавать доступ читателям и скрывать суммы на экране.

## Возможности

- Доходы и расходы по одному счету.
- Общие категории с цветными тегами.
- Быстрое добавление, копирование, изменение и просмотр операций.
- Поиск по описанию, категории и сумме.
- Фильтры по типу, категориям, годам, месяцам, дням и диапазону дат.
- Автоматическая подгрузка операций при прокрутке.
- Диаграммы доходов и расходов по категориям.
- Режим приватности с иконкой глаза: суммы заменяются на точки.
- CSV-импорт и экспорт.
- Google Drive для ведущего устройства и читателей.
- Шифрование облачного файла на устройстве.

## Запуск локально

Требуется Node.js 18 или новее.

```powershell
node --version
npm run dev
```

Приложение откроется по адресу `http://127.0.0.1:4173`.

Локальный сервер автоматически обновляет страницу при изменении `index.html`, `styles.css`, `app.js`, `manifest.webmanifest` или `sw.js`.

## Установка как приложение

Откройте опубликованную версию в Chrome на Android или Safari на iOS и выберите установку приложения из меню браузера. После обновления сайта откройте приложение заново; сервис-воркер загрузит новую версию.

## Данные на устройстве

Операции, категории, настройки Google Drive, режим скрытия сумм, пароль-фраза редактора и ключ расшифровки хранятся только в локальном хранилище браузера данного устройства.

Кнопка «Очистить локальные данные» удаляет всё перечисленное. После сброса устройство не сможет расшифровать старый облачный файл без прежней ссылки читателя или прежнего устройства редактора.

## Google Drive: редактор

1. Откройте Google Cloud Console под аккаунтом редактора.
2. Включите Google Drive API.
3. Создайте OAuth Client ID типа `Web application`.
4. Добавьте `https://tpskym.github.io` в Authorized JavaScript origins.
5. В MoneyFlow откройте настройки, оставьте вкладку «Редактор».
6. Укажите OAuth Client ID и пароль-фразу шифрования, затем нажмите «Сохранить настройки».
7. Нажмите «Выгрузить в облако». При первой выгрузке будет создан файл Google Drive.
8. Укажите Gmail читателя и откройте ему доступ на чтение.
9. Отправьте читателю ссылку подключения через личный мессенджер.

Редактор может загрузить данные из облака в настройках. Такая загрузка заменяет локальные операции и категории.

## Google Drive: читатель

1. Получите доступ к файлу на Gmail от редактора.
2. Откройте ссылку подключения или вставьте её в настройках на вкладке «Читатель».
3. Нажмите «Подключиться по ссылке».
4. Нажмите «Синхронизировать».

Читатель не вводит пароль-фразу и не может менять операции. Ссылка уже содержит ключ, нужный для расшифровки файла.

## Шифрование

Перед выгрузкой редактор задаёт пароль-фразу. Приложение локально получает из неё ключ `AES-256` через `PBKDF2-HMAC-SHA-256` с 600 000 итераций и шифрует весь JSON-файл алгоритмом `AES-GCM`.

В Google Drive попадает только шифротекст, случайный `IV`, соль и технические параметры. Сам пароль-фраза в облако не отправляется.

Для читателя приложение передаёт готовый ключ в части ссылки после `#`. Этот фрагмент не передаётся GitHub Pages или Google Drive, но его нужно считать секретом: не публикуйте ссылку и не отправляйте её в общие чаты.

При изменении пароль-фразы редактор должен:

1. Сохранить настройки.
2. Выгрузить данные в облако.
3. Отправить читателям новую ссылку подключения.

Старые ссылки не смогут расшифровать новую выгрузку.

## Импорт и экспорт CSV

В настройках доступны кнопки «Выгрузить в файл» и «Загрузить из файла». Импорт доступен только редактору и полностью заменяет локальные операции и категории. CSV-файл не шифруется, поэтому не используйте его как защищённую резервную копию.

## Публикация

Проект размещён на GitHub Pages: <https://tpskym.github.io/moneyflow-webapp/>.

После изменения статических файлов нужно повысить версию в `index.html` и имя кэша в `sw.js`, затем отправить изменения в ветку `main`. GitHub Pages обычно обновляется в течение нескольких минут.

## Структура

- `index.html` — разметка и формы.
- `styles.css` — мобильная адаптация и стили.
- `app.js` — операции, фильтры, Google Drive, CSV и шифрование.
- `sw.js` — офлайн-кэш и обновление PWA.
- `manifest.webmanifest` — метаданные устанавливаемого приложения.
